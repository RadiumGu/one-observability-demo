## 🔐 Cognito 认证流程

```
┌────────────┐
│ 用户访问   │
│ 应用 URL   │
└──────┬─────┘
       │
       ▼
┌────────────────────────┐
│ ALB 检查认证 Cookie     │
│ (AWSELBAuthSessionCookie)│
└──────┬─────────────────┘
       │
       ├──────────────────────────────┐
       │                              │
       ▼ 未认证                       ▼ 已认证
┌──────────────────┐         ┌──────────────────┐
│ 302 重定向到     │         │ 转发请求到后端    │
│ Cognito Hosted UI│         │ (添加用户信息头)  │

       │                              │
       ▼                              ▼
┌──────────────────┐         ┌──────────────────┐

│ (邮箱 + 密码)    │         │ (可读取用户信息)  │

       │
       ▼
┌──────────────────┐
│ Cognito 验证     │

└──────┬───────────┘
       │
       ▼
┌──────────────────┐

       ▼
```

## 📈 性能对比

```
之前 (多 ALB):
用户 → ALB 1 → Service 1
        (~5ms)   (~20ms)

之后 (统一 ALB):
用户 → ALB → 路由 → Service
        (~5ms) (~1ms) (~20ms)

额外延迟: +1ms (路由开销，可忽略)
```

### Cognito 认证延迟

```
首次登录:
用户 → ALB → Cognito → ALB → Service
        (~200-500ms 一次性开销)

后续请求:
用户 → ALB → Service
        (Cookie 验证, ~1ms)
```
